# دليل استخدام نظام الذهب — AlMuhasib

هذا الدليل يشرح كيفية التعامل مع **نظام محل الذهب** في AlMuhasib، وعلاقته بأسلوب العمل الشائع في محلات الذهب في **العراق**.

---

## 1. مفاهيم أساسية

| المصطلح | المعنى |
|---------|--------|
| **العيار** | نقاوة الذهب: 24، 22، 21، 18 (يُعرَض في القوائم المنسدلة — وليس «المعيار») |
| **المثقال** | وحدة وزن تقليدية (~5 غرام افتراضياً في الإعدادات) — يُسعَّر الذهب بسعر المثقال اليومي |
| **أجور الصياغة** | تكلفة العمل/الصياغة بالإضافة لقيمة الذهب |
| **سعر الصرف** | تحويل USD → IQD عند التسعير أو الدفع بعملة مختلفة |

---

## 2. طريقتان للبيع

### أ) البيع بالعيار والوزن (الأكثر شيوعاً)

من **فاتورة بيع ذهب**:
1. حدّث **أسعار المثقال** لليوم (من قائمة التسعير).
2. سجّل **سعر الصرف** إن لزم.
3. أضف بنداً: اختر **العيار** → أدخل **الوزن** (من الميزان أو يدوياً).
4. يُحسب تلقائياً: قيمة الذهب + أجور الصياغة = إجمالي البند.
5. عند الحفظ يُخصم الوزن من **مخزون العيار** في المخزن المحدد.

**متى تستخدمها:** سكراب، سبائك، بيع بالوزن دون تتبع قطعة بقطعة — كما في أغلب محلات الذهب العراقية.

### ب) البيع بقطعة مسجّلة (أصناف الذهب)

من شاشة **أصناف الذهب**:
1. سجّل كل قطعة (اسم، باركود، عيار، وزن، أجور، تكلفة).
2. يمكن **تنزيل قالب Excel** و**استيراد** أصناف دفعة واحدة.
3. في فاتورة البيع، أدخل **رقم القطعة أو الباركود** في عمود «قطعة / باركود» — يُملأ العيار والوزن والأجور تلقائياً.
4. عند الحفظ تُ marked القطعة **مباعة** ولا تُباع مرتين.

**متى تستخدمها:** خواتم، سلاسل، قطع جاهزة في vitrine — عندما تحتاج باركود وتتبع كل قطعة.

---

## 3. متى أحتاج «أصناف الذهب»؟

| الحالة | هل أحتاج أصناف الذهب؟ |
|--------|------------------------|
| بيع وزن حسب العيار فقط | **لا** — يكفي سطر الفاتورة بالعيار |
| مخزون قطع جاهزة + باركود | **نعم** |
| طباعة ملصقات / تتبع حالة كل قطعة | **نعم** |
| شراء خردة من مورد | **لا** — فاتورة الشراء بالعيار والوزن |

---

## 4. سير العمل اليومي المقترح

```text
صباحاً:
  1) تحديث أسعار المثقال (كل العيارات)
  2) تسجيل سعر الصرف USD → IQD
  3) مراجعة التنبيهات (أسعار، ذمم، مخزون)

أثناء اليوم:
  • بيع → فاتورة بيع (ميزان + عيار)
  • شراء خردة → فاتورة شراء
  • تبديل → فاتورة تبديل (وارد + صادر)
  • تحصيل ذمم → شاشة التحصيل

مساءً:
  • تسجيل مصروفات اليوم
  • مراجعة تقارير المخزون والقاصة
```

## 5. التشابه مع أنظمة العراق

النظام مبني على ممارسات شائعة في **بغداد، البصرة، أربيل** وغيرها:

- **التسعير بالمثقال** وليس بالغرام فقط في واجهة البيع (مع تحويل داخلي).
- **معادلة قيمة الذهب:** `الوزن × (سعر المثقال ÷ وزن المثقال)` — سعر المثقال لكل عيار جاهز (مثل عيار 21)، **دون ضرب نقاوة العيار مرة ثانية**.
- **العيار 21** الأكثر استخداماً في المجوهرات، مع 22 و24 للسبائك والخردة.
- **أجور الصياغة** منفصلة عن سعر الذهب.
- **صندوق دينار + صندوق دولار** و**سعر صرف يومي**.
- **ذمم زبائن** (نقدي / آجل) و**ذمم موردين** في الشراء.
- **فاتورة تبديل** (ذهب قديم ↔ جديد) مع فرق نقدي.

لا يُ claim أن النظام نسخة حرفية من برنامج معيّن — بل **متوافق مع أسلوب العمل المحلي** مع إضافة تتبع مخزني وتقارير ونسخ احتياطي.

## 6. الشاشات الرئيسية

| الشاشة | الغرض |
|--------|--------|
| لوحة التحكم | ملخص مبيعات، مخزون، ذمم، تنبيهات |
| أسعار المثقال | تسعير يومي لكل عيار |
| أسعار الصرف | USD → IQD (متاح أيضاً من زر «سعر الصرف» أسفل التبويبات) |
| أصناف الذهب | قطع مسجّلة + Excel |
| فاتورة بيع / شراء / تبديل | العمليات اليومية |
| الزبائن / الموردين | بيانات الأطراف + ذمم |
| التنبيهات | أسعار غير محدّثة، مخزون منخفض، ذمم متأخرة |

---

## 7. إعداد أول مرة

1. **الإعدادات**: وزن المثقال، العيارات المفعّلة، الميزان (COM).
2. **الصناديق**: دينار ودولار (تُنشأ افتراضياً).
3. **المخزن الافتراضي** والعيارات (24، 22، 21، 18).
4. **أسعار المثقال** و**سعر الصرف** قبل أول عملية بيع.

---

## 8. أسئلة شائعة

**س: قائمة العيار فارغة؟**  
ج: تأكد من تشغيل النظام بعد التحديث — يتم إنشاء العيارات الافتراضية تلقائياً. أو افتح **الإعدادات** مرة واحدة.

**س: بعت بالعيار فقط بدون قطعة — ماذا يحدث للمخزون؟**  
ج: يُخصم الوزن من رصيد **العيار** في المخزن، لا من «أصناف الذهب».

**س: الفرق بين التصدير والاستيراد في أصناف الذهب؟**  
ج: **تصدير** = نسخة من البيانات الحالية. **قالب + استيراد** = إدخال دفعة أصناف جديدة من Excel.
