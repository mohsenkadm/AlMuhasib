# لقطات شاشة الموقع

ضع هنا صوراً حقيقية من النظام لاستبدال المعاينة المبنية بـ CSS تلقائياً:

| الملف | الاستخدام |
|-------|-----------|
| `desktop-dashboard.png` | أعلى الصفحة — الشاشة الرئيسية للنظام الأوفلاين |
| `mobile-app.png` | قسم التطبيق الجوال — واجهة التطبيق القادم |

**التوصيات:** PNG أو WebP، عرض ~1200px للسطح المكتب و~600px للجوال.

إذا لم تُضف الصور، تظهر المعاينة التفاعلية الافتراضية.
